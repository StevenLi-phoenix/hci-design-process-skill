# Changelog

All notable changes to this project are documented here. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versioning: [SemVer](https://semver.org/).

## [0.1.0] - 2026-10-26

### Added
- `SKILL.md`: five-stage user-centered design process (Empathize → Define → Ideate → Prototype → Test) with scaling rules, evidence ladder (primary → traces → requester → assumption) and per-stage exit gates.
- `references/`: empathize (users/stakeholders, interviews, guide construction and closed-question lint, surveys, observation), define (problem statements, qualitative coding, affinity diagrams and their classic errors), ideate (composite personas, storyboards, brainstorming), prototype (fidelity ladder, mental models, gulfs, Fitts, Norman, accessibility), test (usability tests, SUS scoring, Nielsen heuristics, cognitive walkthrough), ethics (research and design ethics, dark patterns).
- `templates/`: problem statement, interview guide, affinity diagram, persona, storyboard, usability test plan.
- `evals/`: 8 `claude plugin eval` cases (6 should-fire, 2 should-not-fire) with outcome graders.
